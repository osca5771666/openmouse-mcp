# 风险说明

## 必须人工监督

鼠标自动化存在误触风险。坐标识别错误、页面布局变化、延迟加载、弹窗、多显示器切换或窗口焦点变化都可能让动作落到错误控件。

不要在没有人工监督的情况下执行支付、删除文件、关闭批量窗口、提交表单、退出账号或修改系统设置。

## 高风险识别不是完整语义理解

插件会检查 Agent 的 `intent`、目标可见文本、ARIA 标签、标题和表单规模。但鼠标工具无法理解所有业务语义：

- 一个名为 “Continue” 的按钮仍可能导致不可逆删除。
- 图标按钮可能没有文本。
- Canvas、游戏、远程桌面和自绘控件无法可靠检查内部语义。

因此 Agent 的 `intent` 必须诚实且具体，用户必须在高风险确认中查看上下文。

## 浏览器合成事件限制

浏览器模式派发的是页面级合成事件，`event.isTrusted` 为 `false`。以下场景可能失败：

- 只接受浏览器可信输入的站点。
- 需要原生右键菜单的操作。
- 跨域 iframe 内部控件。
- 浏览器内置页面、扩展商店、PDF 查看器。
- 强依赖真实键盘焦点或输入法状态的工作流。

合成事件失败不应通过多点几次猜测解决，应停止并报告。

## 截图隐私

Windows 截图可能包含通知、密码管理器、聊天内容、客户数据和令牌。

浏览器截图可能包含当前登录会话和敏感表单内容。

截图内容会进入 Agent 模型上下文和宿主日志。只在必要范围内截图，避免截取敏感页面。不要在公开聊天或未授权设备上运行。

Windows 的 `computer_observe` 会返回全屏画面和可见窗口标题。任务栏可能显示聊天软件、邮箱、客户名称和未读消息，运行前应确认屏幕共享和模型数据策略。

## 重试可能重复动作

单击最多自动重试两次。如果点击已经送达页面，但响应超时或连接断开，重试可能造成重复点击、重复提交或重复购买。

插件无法对所有网页操作提供事务级幂等性。高风险动作应使用确认门，并在每次重试前重新评估页面状态。

## ESC 的边界

- Windows 的全局 ESC 依赖 `pynput` 监听器仍在运行。
- 浏览器页面 ESC 需要受控页面或扩展仍能接收键盘事件。
- 操作系统安全桌面、UAC 提示、锁屏和某些全屏独占程序可能收不到 ESC。
- 进程崩溃、系统卡死或权限隔离时，停止保证会下降。

必要时使用任务管理器终止 Agent 或 MCP 进程。

## 权限与窗口层级

Windows 不允许普通权限进程向管理员权限窗口注入输入。Agent 和目标软件应使用一致的权限等级，或使用明确的受控提权流程。

多显示器、DPI 缩放、远程桌面和虚拟机可能导致截图坐标与实际桌面坐标不一致。应在动作前截图并验证。

## 浏览器扩展权限

扩展请求 `<all_urls>`、标签页、脚本注入和截图能力。这是为了在普通网页上运行虚拟鼠标并捕获当前标签页。

令牌通过本地文件保存。不要将 `.runtime/browser-token.txt` 提交到版本库或发送给不受信任的人。

桥只绑定 `127.0.0.1`，但本机恶意进程仍可能尝试连接。共享令牌可以阻止没有令牌的连接，不能替代系统级安全防护。

## 云端 HTTP 风险

Streamable HTTP 是可远程访问的输入通道。未启用 Bearer Token、TLS 和 Host 白名单时，任何能访问端口的人都可能控制云浏览器或读取截图。

- 必须设置足够长的 `MOUSE_MCP_HTTP_TOKEN`。
- 必须通过 HTTPS 反向代理访问。
- 使用 `MOUSE_MCP_HTTP_ALLOWED_HOSTS` 限制 Host。
- 不要把 `8766` 直接暴露到公网。
- 云浏览器 Cookie 和本地浏览器 Cookie 相互隔离。
- `browser_open` 默认阻断内网地址。只有明确信任云任务访问内网时，才可开启 `MOUSE_MCP_CLOUD_ALLOW_PRIVATE_URLS=1`。
- 地址预检查不能完全消除 DNS rebinding 或浏览器网络栈差异；生产环境仍应配置容器出站网络策略。

云端 MCP 无法直接控制用户本机桌面；本地控制必须在本地启动 stdio MCP。

## 模型行为风险

模型可能：

- 坐标换算错误。
- 将旧截图用于新页面状态。
- 把高风险操作描述得过于模糊。
- 在失败后连续尝试附近坐标。

系统提示词要求截图验证、明确 intent、失败停止和人工确认。宿主还应配置工具审批、沙箱和最大轮次限制。

## 合规

仅操作你有权控制的设备、账户和网页。遵守目标网站条款、隐私法规和组织安全策略。

插件的人性化轨迹和随机停顿用于降低机械误触，不承诺规避网站风控，也不应被用于绕过访问控制、反欺诈或未经授权的自动化。
